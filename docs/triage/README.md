# Triage board

`index.html` is generated by `build_board.py` from the checked-in upstream
state in `snapshot-2026-10-23.json`. Building and testing need no network:

```sh
python3 docs/triage/build_board.py
python3 docs/triage/test_board.py
node docs/triage/test_board.cjs
```

The triage calls (bucket, reason, next step, suggested message) live in the
`pr(...)` and `issue(...)` overlays in `build_board.py`. The research notes and
the changelog since the first snapshot are in
`2026-09-03-open-prs-and-issues.md`.

## Refreshing the snapshot

Fetch the open queue with the GitHub CLI into a dated snapshot file:

```sh
python3 - <<'EOF'
import datetime, json, subprocess
def gh(*args):
    return json.loads(subprocess.check_output(["gh", *args, "--repo", "rrweb-io/rrweb", "--state", "open"]))
prs = gh("pr", "list", "--limit", "500", "--json", "number,title,url,author,createdAt,updatedAt,isDraft,reviewDecision,labels,additions,deletions,changedFiles,mergeable")
issues = gh("issue", "list", "--limit", "1000", "--json", "number,title,url,author,createdAt,updatedAt,labels")
today = datetime.date.today().isoformat()
snapshot = {"taken": today, "repo": "rrweb-io/rrweb",
            "pr": sorted(prs, key=lambda p: -p["number"]),
            "issue": sorted(issues, key=lambda i: -i["number"])}
with open(f"docs/triage/snapshot-{today}.json", "w") as f:
    json.dump(snapshot, f, indent=1, ensure_ascii=False)
    f.write("\n")
print(len(prs), "PRs,", len(issues), "issues")
EOF
```

Point `SNAPSHOT` in `build_board.py` at the new file, delete the old one, and
update the dates in the page header.
`test_board.py` then lists every open PR without an overlay and every overlay
whose item has closed, so the refresh is done when it passes.

## Done marks

Opened as a claude.ai artifact, the board keeps Done marks in the artifact's
shared store and every viewer sees them live. Opened anywhere else (GitHub
Pages, a local file), marks stay in that browser's `localStorage` under one
key that does not change between snapshots.
